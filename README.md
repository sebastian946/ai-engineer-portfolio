# AI Engineer Portfolio

[![README check](https://github.com/sebastian946/ai-engineer-portfolio/actions/workflows/readme-check.yml/badge.svg)](https://github.com/sebastian946/ai-engineer-portfolio/actions/workflows/readme-check.yml)

This is the hub for my applied AI engineering work: production-minded projects built around LLMs, retrieval-augmented generation (RAG), agents and evaluation pipelines. Every project here ships with a reproducible setup, a measured evaluation, a cost and latency breakdown, and an honest list of limitations, because an AI system you cannot measure is one you cannot trust in production.

**Target roles:** AI Engineer · LLM Application Engineer · Applied ML Engineer (RAG, agents, evals).

## How this portfolio works

- Every project follows the same README contract defined in [templates/PROJECT_README.md](templates/PROJECT_README.md).
- Naming, branching, commits, folder structure, secrets policy and evaluation requirements live in [CONVENTIONS.md](CONVENTIONS.md).
- A CI check ([scripts/check_readme.py](scripts/check_readme.py)) fails any README that is missing a mandatory section.
- Progress and lessons are tracked in [LEARNING_LOG.md](LEARNING_LOG.md).
